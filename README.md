# 2027 考研政治一页纸 · 智能背诵与真题模拟题刷题系统

> 本项目基于澄潇宇《2027 考研政治一页纸：知识点手册》与《政治解题方法一页纸》，打造高度还原、沉浸交互的考研政治数字化备考系统。
> 集**核心知识点艾宾浩斯智能背诵**、**原书高频考点对应真题与名师模拟题库**、**老头命题 10 类挖坑手法剖析**与**四大解题思维模式**于一体，支持 PC 桌面端与移动手机端全适配，具备 100% 离线脱网运行能力。

---

## 🌟 核心特性

### 1. 📖 知识点浏览与智能背诵（双核心之一）
- **122 张精编知识卡片**：100% 覆盖原书 100 个核心考点，包含马原、毛中特、史纲、思修法治与当代五大部分。
- **全格式考点还原**：
  - 核心关键词多级层级高亮；
  - ⚡ 概念辨析与命题陷阱（正误表述对比）；
  - 💡 原书速记口诀（内嵌趣味助记贴纸，纯透明背景，还原原书风味）；
  - 📊 置顶考点原始脉络图（如考点037史纲脉络清晰回溯）。
- **随卡一键切换背诵模式**：
  - **原文**：完整展示全部文字；
  - **挖词**：自动挖空原书高频重点词汇，点击单个即可即时揭晓；
  - **随机**：随机隐藏句子主干与细节，强化主动回忆；
  - **全遮**：整卡遮挡，主动输出后一键核对回忆。
- **艾宾浩斯 SRS 间隔复习**：生疏、模糊、掌握、熟练四级自评，智能调度下次复习周期，弱项自动归入错题本。

### 2. 🎯 原书考点对应真题与名师模拟题（Markji 深度融合）
- **1,061 道题目精准关联**：
  - 🔴 **历年真题（589 题）**：严格按年份升序与真题序号排布（如 `2011-1`, `2018-4`, `2019-1`, `2021-1` 等）；
  - 🔵 **名师模拟题（472 题）**：囊括肖秀荣（四套卷/八套卷）、徐涛（六套卷）、腿姐（四套卷）、米鹏、新东方、苏一、余峰等名师精选模拟题。
- **沉浸式交互做题弹窗（Practice Modal / Bottom Sheet）**：
  - 点击考点下方任意题目胶囊即可唤起做题卡；
  - 单选/多选自适应交互点选；
  - 一键提交答案，自动对比正误（绿标正确项、红标错选干扰项）；
  - 展开权威详尽解析与对应考点归属；
  - 本地做题记录自动持久化（`localStorage`），考点卡片上的题目胶囊实时同步显示 `✓`（正确）或 `✗`（错误）。

### 3. ✍️ 真题模拟题解题刷题系统（双核心之二）
- **🎯 10 类命题挖坑手法库**：概念混淆、范围扩大、时态颠倒、因果倒置、主次颠倒等固定设坑机制拆解与防坑要诀；
- **⚡ 四大解题思维模式**：单选题三项解题法、多选题疑罪从无排除法、马哲不全选心法深度总结；
- **📖 马恩列经典名言避坑表**：真题曾考查的高难度抽象原话精选集，防止因“读不懂”而误判；
- **⚰️ 18 大高频墓碑词敏锐雷达**：考场敏感词专向监控；
- **📝 分类刷题 / 👁️ 盲测识坑 / ⏱️ 限时模考 / 📊 统计看板 / 📕 错题本**。

### 4. 📱 手机移动端深度优化
- 顶部导航升级为**原生胶囊分段控制器**（Segmented Control），大拇指轻松单手触达；
- 适配动态视口高度（`100dvh`）与全面屏安全边距（`safe-area-inset-bottom`），彻底杜绝浏览器底栏遮挡；
- 考点题目弹窗在手机端自动转为**底部上滑抽屉（Bottom Sheet）**；
- 支持左右滑动手势快速切卡，并配备边缘防误触退出机制。

## 🚀 本地开发与部署运行

### 本地运行工程
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 运行自动化测试（29 项测试套件）
npm test

# 生产环境打包构建
npm run build
```

### 生成单文件离线 HTML
```bash
# 生成纯净精简离线版
python scripts/generate_standalone_lite_html.py

# 生成全功能发布版
python scripts/generate_standalone_html.py
```

## 🌐 GitHub Pages 在线部署说明

本项目已配置 GitHub Actions 自动构建与部署工作流（`.github/workflows/deploy.yml`）。
将代码推送到 GitHub 的 `main` 分支后：
1. 打开 GitHub 仓库设置 `Settings` -> `Pages`；
2. 在 `Build and deployment` -> `Source` 中选择 **GitHub Actions**；
3. GitHub Actions 将自动完成打包并将网站发布到 `https://<你的用户名>.github.io/<仓库名>/`。

# 关键词连贯性 & 趣味图标保留:审查与修改建议

数据来源:`data/knowledge.json`(122 张卡片),审查脚本 `scripts/audit_keywords.py`,明细 `reports/kwaudit.txt`。

## 一、关键词不连贯(核心问题)
**统计**:2263 个高亮片段中,375 个只有 1 个字;381 处是"同色且紧挨着"的片段被切开;98/122 张卡片受影响。
**根因**:关键词是按 PDF 的颜色/字体 span 提取的,同一个词只要换行、或中间夹了不同字体就被切成几段。

**典型例子**

| 卡片 | 现状 | 建议 |
|---|---|---|
| kp-003-01 上层建筑 | `{{政治法律思}}{{想}}` | `{{政治法律思想}}` |
| kp-005-01 | `{{劳}}{{动}}{{二}}{{重性理论}}` | `{{劳动二重性理论}}` |
| kp-002-01 | `{{科}}{{学性与革}}{{命}}{{性的统一}}` | `{{科学性}}与{{革命性}}的统一({{科}}{{命}})`,保留"科命"口诀 |
| kp-002-01 | `{{彳亍}}` | 疑为原文趣味拆字("行"),保留,但补注释"彳亍=行" |
| kp-003-01 | `{{主导地位}}`/`{{核心}}` 全卡共 10 片段 | 可保留,仅合并相邻同色段 |

**修改规则**(可写成脚本自动处理,再人工复核)
1. 相邻且同色的片段,中间无字符或只有标点/空格 → 合并为一个关键词。
2. 单字片段:若与前/后片段同色且相邻 → 并入;若孤立的单字(如"科""命"口诀字) → 保留,并在 `mnemonics` 字段标明。
3. 合并后用词典校验:把切断的词(如"政治法律思想""劳动二重性")与知识点标题、章节名比对,命中则强制整体高亮。
4. 重点人工复核的卡片:kp-013-01(70 片段/14 单字/12 处近邻)、kp-046-01、kp-041-01、kp-010-01、kp-020-01、kp-031-01、kp-044-01、kp-067-01。
5. 背诵"关键词模式"按合并后的词挖空,避免"{{政治法律思}}想"这种半个词被挖掉的问题。
6. 合并后给每张卡片 `reviewStatus` 标 `needs-review`→人工通过才改为 `verified`(目前 122 张全是 needs-review,0 张 verified)。

## 二、趣味图标保留
**现状**:原书里的小图(国旗、工农革命旗、直升机、帽子人物、鸡、机器多了/工人少了等,共 39 张,见 `docs/symbol-mapping.md`)被转成 `{俄国国旗}`、`{直升机}` 这样的文字占位,`CardViewer.vue` 里用 `symbol-chip` 以文字小标签显示,原图并没有显示出来。部分卡片还有占位符漏转(14 张卡片正文带 `{...}`)。
**建议**
1. 把 `public/images/` 下已抽出的 192×192 原图,按 `symbols[].hash` 映射渲染为行内小图(高度约 1.2em),文字占位仅作 alt/备用。
2. 对映射表里状态为"待确认"的图标(如 #07、#12、#13、#14、#15、#16、#18、#19、#20、#28、#34、#36、#37),逐个对 PDF 页面核对含义后再启用。
3. 常用 emoji(✅❌⚠️➔⭐❗💡🚩)继续用 emoji 渲染;原书特有的趣味图用原图,保持"风趣味"。
4. 助记图标单独加一层"助记提示":鼠标悬停/点击显示 `desc`(如"牢二枢纽直升机""偷鸡心虚虚空鸡"),背诵时可开关。
5. 挖空模式下不要挖掉图标,而是把图标当线索保留;自评页可显示"图标线索"。
6. 24 张卡片没有任何符号,属正常(原文无图标),不用补。

## 三、实施顺序
1. 跑合并脚本(规则 1-3),输出 diff 供人工看。
2. 人工复核标红卡片,通过的标 `verified`。
3. 渲染层改用原图(CardViewer),补测试用例:合并后无"半个词"、占位符 0 残留。
4. 回归:`npm.cmd test`、`npm.cmd run build`,并重新生成单文件 HTML。

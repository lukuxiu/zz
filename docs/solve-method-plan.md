数据来源:两份 PDF(思维导图,1-4 / 5-10 为两个分页)。题号格式 `年份.题号`(如 2022.21,为真题选择题)。

## 一、解题方法(来自一页纸)
**思维模式**:①没见过不等于错,有印象不等于对;②善用排除法;③时政观从未见过的单选题找材料相同词;④多选思维模式(排除 + 全选倾向,马哲多选几乎不可能全选)。

## 二、网站功能规划
项目 `zhengz` 已有 Vue + Vite 的背诵站(`src/`、`data/knowledge.json`),建议**在原站新增「解题方法刷题」模块**,复用 SRS 与错题本。

1. **方法库**:10 类方法卡片,含识别口诀、关键词高亮(橙色词)、典型坑。
2. **分类刷题**:按方法进入;题目显示题干 + 选项,作答后给出答案与"一页纸"解析(如"排除C,选ABD"),并标注命中的方法。
3. **盲测模式**:先不告知类别,答完让你选"这题用了哪种手法",训练识别。
4. **错题 / 薄弱方法**:统计每类正确率,复用 `docs/srs.md` 的间隔复习,错题按方法聚合。
5. **混合模拟**:按年份或随机抽题,限时。
6. **进度看板**:各方法完成度、正确率、方法×年份热力图。

## 三、数据结构
```json
{ "id":"2022.21", "year":2022, "no":21, "type":"multi",
  "stem":"...", "options":{"A":"","B":"","C":"","D":""},
  "answer":["A","B"], "methods":["hedge"],
  "tip":"C、D 过于绝对,排除" }
```
`methods.json`:id、名称、口诀、关键词、题目 id 列表。

## 四、实施步骤
1. **数据**(1-2 天):从 PDF 抽题干/选项;答案与解析是红蓝字批注(难 OCR),需半自动加人工校对。当前可先用题号索引建站,题干后补。
2. **页面**(2-3 天):方法库、刷题、结果页。
3. **统计/SRS 接入**(1-2 天)。
4. **盲测、模拟、看板**(1-2 天)。
5. 打包为单 HTML(沿用 `scripts/generate_standalone_html.py`)便于离线使用。

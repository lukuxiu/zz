# 间隔复习与记忆管理算法规范 (SRS.md)

本文档定义考研政治一页纸智能背诵系统的记忆算法（Spaced Repetition System）、评价流转机制与错题生命周期。

## 一、核心设计哲学

1. **原书知识只读**：算法仅对用户学习记录（`user_records`）产生状态读写，绝对不修改 `knowledge.json` 中的任何知识点内容。
2. **重在薄弱点攻克**：“完全不会”与“模糊”的知识点获得最高的调度权重与复现频次。
3. **低认知负担**：用户只需在每次背诵完毕后进行简单的四档自我评价，算法自动计算下一次复习时间与优先级。

---

## 二、四档自我评价与初始复习间隔

| 评价等级 (`grade`) | 含义与判定标准 | 初始下次复习间隔 | 是否自动入错题本 | 内部权重等级 |
|---|---|---|---|---|
| **完全不会** (`again`) | 完全没有印象、关键词无法回忆 | 当天再次复现（建议 10~30 分钟或本轮末尾） | **是** | 优先级 1（最高） |
| **模糊** (`hard`) | 仅记得大概或部分词，需要提示 | 1 天后 (`+24 hours`) | **是** | 优先级 2 |
| **基本掌握** (`good`) | 能准确回忆核心关键词，逻辑通顺 | 3 天后 (`+72 hours`) | 否（若已在错题本则计1次恢复） | 优先级 3 |
| **熟练掌握** (`easy`) | 毫不费力回忆全文、口诀及辨析 | 7 天后 (`+168 hours`) | 否（若已在错题本则计1次恢复） | 优先级 4 |

---

## 三、进阶调度与长期间隔延长算法

每个知识点维护以下学习状态字段：
```typescript
interface LearningRecord {
  cardId: string;              // 对应 knowledge.json 的 id (如 kp-001-01)
  reviewCount: number;         // 累计复习次数
  consecutiveGood: number;     // 连续达到“基本掌握”或“熟练掌握”的次数
  lastReviewTime: number;      // 最近复习时间戳 (毫秒)
  nextReviewTime: number;      // 下次应复习时间戳 (毫秒)
  lastGrade: 'again' | 'hard' | 'good' | 'easy';
  isFavorite: boolean;         // 是否收藏
  inMistakeBook: boolean;      // 当前是否在错题本中
  history: Array<{
    timestamp: number;
    grade: 'again' | 'hard' | 'good' | 'easy';
    mode: 'keyword' | 'sentence' | 'random' | 'full';
    intervalHours: number;
  }>;
}
```

### 1. 连续掌握加权算法
- 当用户评价为 `easy`（熟练掌握）：
  - 若 `consecutiveGood == 0`：间隔为 7 天。
  - 若 `consecutiveGood == 1`：间隔延长至 14 天。
  - 若 `consecutiveGood >= 2`：间隔延长至 $\text{上一次间隔} \times 2.2$（例如约 30 天、66 天等，最大上限 120 天）。
- 当用户评价为 `good`（基本掌握）：
  - 若 `consecutiveGood == 0`：间隔为 3 天。
  - 若 `consecutiveGood >= 1`：间隔为 $\text{上一次间隔} \times 1.6$。

### 2. 遗忘重置机制 (Lapse)
- 一旦用户在任何一次复习中评价为 `again`（完全不会）：
  - `consecutiveGood` 立即清零为 0。
  - 自动打上 `inMistakeBook = true` 标签。
  - 下次复习时间重设为当前时间（当天内尽快再次出现）。
- 若评价为 `hard`（模糊）：
  - `consecutiveGood` 减半或重置为 0。
  - 自动打上 `inMistakeBook = true`。
  - 下次复习时间设为当前时间 + 1 天。

### 3. 同轮防连续出现机制
- 在当前会话（Session）的待复习队列中，对于评价为“完全不会”而需要重新入队的知识点，插入到队列末尾或至少相隔 3 张其他卡片之后，避免用户产生短期视觉暂存记忆的错觉。

---

## 四、错题本移出与流转规则

1. **进入错题本**：凡单次评价为 `again` 或 `hard` 的卡片，立即进入错题本列表。
2. **移出当前错题列表**：
   - 必须**连续 2 次**评价为 `good` 或 `easy`，方可将 `inMistakeBook` 置为 `false`，从当前活跃错题列表中移出。
   - 移出后，其历史评价日志（`history`）仍然**永久完整保留**，可在知识点历史记录中回溯。
3. **错题本筛选**：错题本支持按科目（马原、政经、史纲、其他）及章节进行精细化专项突击。

---

## 五、随机抽查（Quiz）去重规则

1. 每次开始随机抽查时，根据用户选定的范围（全部 / 按学科 / 仅错题 / 仅收藏）生成候选 ID 池。
2. 每次抽取后，将该 ID 从当次会话的可用池中移除，**保证一轮抽查中绝不出现重复卡片**。
3. 当可用池全部抽完时，提示用户已完成本轮抽查，并展示本轮总体掌握率统计，由用户决定重新开始或退出。

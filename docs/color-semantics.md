# PDF 文字颜色语义映射文档 (Color Semantics)

本文档基于对《27考研政治一页纸-知识点手册.pdf》内容页（第11至35页）全文实际提取的文字 span 颜色值进行的精确统计与语义定义。

## 一、颜色提取总体原则

1. **唯一来源**：颜色值直接来自 PDF 矢量文字层 span 对象的 `color` 属性（十六进制整数）。
2. **弱化文字单独隔离**：`0xaaaaaa` 绝对禁止作为重点关键词（禁止包裹 `{{...}}`），网站中以弱化低对比度显示。
3. **普通文字保持原样**：`0x555555`, `0x5d5d5d`, `0x000000` 属于普通文字，不标记为关键词。
4. **重点彩色词抽取**：红色、蓝色、橙色、青蓝色、红褐色等具有明确强调意图的颜色作为关键词，在正文中使用 `{{词语}}` 包裹，并记入 `keywords` 列表。
5. **不跨标点**：连续重点色 span 遇到标点符号（，。；！？等）时截断，避免将整句错误识别为单一关键词。

## 三、知识库提取行为定义

1. **关键词识别集合**：
   `KEYWORDS_COLORS = { 0x9fff, 0x2000ff, 0xff0000, 0xff6000, 0x275bd1, 0xd16056, 0x40ff, 0xdc7705, 0x8000ff, 0x6783cf, 0xff00bf, 0xeb9e27, 0xdf00ff, 0x20ff00, 0x36b59d }`
2. **弱化文字处理**：
   `MUTED_COLORS = { 0xaaaaaa }`，不打标签，不进入 `keywords`，在 `contentHtml` 中保留 `<span class="muted-text">`。
3. **普通正文**：
   `PLAIN_COLORS = { 0x555555, 0x5d5d5d, 0x000000, 0x90959b }`。
4. **标题与装饰色**：
   `TITLE_COLORS = { 0x98521c, 0xbd3f3f, 0x964a49, 0x178344 }`。
